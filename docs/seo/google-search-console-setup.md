# Google Search Console Setup

## Property

- Preferred property type: Domain property
- Domain: `takelumadaily.com`
- Alternate URL-prefix property: `https://takelumadaily.com`

## Verification Options

Use one of these, in order of preference:

1. DNS TXT verification through the domain DNS provider.
2. Shopify domain verification if Shopify owns the live storefront path.
3. HTML meta verification only if DNS verification is unavailable.

Do not hardcode a verification token until Google provides the exact value.

## Sitemap

Submit this sitemap after deployment:

`https://takelumadaily.com/sitemap.xml`

## Initial Checks

- Confirm the domain does not redirect to a password page before requesting indexing.
- Inspect the homepage URL.
- Inspect `/shop`.
- Inspect the five core product URLs.
- Confirm Google can fetch rendered HTML.
- Check indexing status after 24-72 hours.
