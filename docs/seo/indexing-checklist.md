# Indexing Checklist

## Pre-Indexing

- [ ] `takelumadaily.com` resolves to the intended public storefront.
- [ ] Store password page is disabled for launch.
- [ ] Homepage returns 200.
- [ ] `/shop` returns 200.
- [ ] `/quiz` returns 200.
- [ ] Product pages return 200.
- [ ] No important page has `noindex`.
- [ ] `robots.txt` is reachable.
- [ ] `sitemap.xml` is reachable.

## Launch Checks

- [ ] Submit sitemap in Google Search Console.
- [ ] Inspect homepage and request indexing.
- [ ] Inspect `/shop` and request indexing.
- [ ] Inspect one product URL and request indexing.
- [ ] Check canonical selected by Google.
- [ ] Monitor Coverage and Page Indexing reports.

## Post-Launch

- [ ] Review query data weekly.
- [ ] Identify pages with impressions but low CTR.
- [ ] Improve titles and descriptions with compliant language.
- [ ] Add helpful content pages only when they serve real customer intent.
