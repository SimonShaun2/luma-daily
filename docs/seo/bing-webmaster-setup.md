# Bing Webmaster Tools Setup

## Setup

- Add `takelumadaily.com` as a site.
- Import from Google Search Console after GSC is verified, or verify separately with DNS TXT.

## Submit

- Sitemap: `https://takelumadaily.com/sitemap.xml`
- Core pages: homepage, shop, quiz, about, products.

## Checks

- Confirm `robots.txt` allows Bingbot.
- Confirm product URLs resolve without password protection.
- Use URL inspection for at least one product page.
