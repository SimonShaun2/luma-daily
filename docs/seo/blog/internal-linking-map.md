# Luma Daily — Blog Internal Linking Map

A precise, machine-checkable link map for every article. This file is the source of truth used during the SEO review pass before each article publishes. If a link required by this map is missing, the article doesn't ship.

**Format per article:**
- **Mandatory outbound links** (must be present in body)
- **Recommended outbound links** (add when contextually appropriate)
- **Mandatory inbound links** (other articles MUST link here)

---

## Universal rules (apply to every blog article)

Every article must include, at minimum:

- **1 link** to its **cluster pillar page** (top of article, anchor: cluster name, e.g. "energy + focus support guide")
- **1 link** to the **most-relevant PDP** (contextual, in body)
- **1 link** to the **Find My Ritual quiz** (mid-article, button or text)
- **1 link** to the **most-relevant bundle** (after main content)
- **2-3 links** to **sibling articles** in the same cluster (footer "related reads" block)
- **0-1 links** to **another cluster's pillar** (if the article spans clusters)

**Total outbound minimum:** 6 links per article. **Cap:** 15.

## Audit checklist (run weekly)

Before publish:

- [ ] Article has its mandatory outbound links per this map
- [ ] Anchor text varies (no exact-match keyword on every link to a single page)
- [ ] No broken internal links (404 check)
- [ ] Each link opens in same tab (`target="_blank"` only for external)

After publish (week +1):

- [ ] Inbound links exist as required (other articles link in)
- [ ] Cross-link from 2-3 existing articles back to this one
- [ ] Update the cluster pillar's spoke list to include this URL

After publish (month +1):

- [ ] GSC inspection: indexed?
- [ ] Internal link count from GSC's Links report ≥ 5
- [ ] Top inbound anchor variants documented
