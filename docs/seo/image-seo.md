# Image SEO Guide

## Naming

Use descriptive, product-specific filenames before uploading or committing images.

Examples:

- `luma-energy-blood-orange-mango-gummies.jpg`
- `luma-calm-raspberry-hibiscus-gummies.jpg`
- `luma-sleep-blueberry-lavender-gummies.jpg`
- `luma-glow-strawberry-peach-beauty-gummies.jpg`
- `luma-gut-citrus-mint-digestive-gummies.jpg`
- `luma-daily-full-ritual-gummy-bundle.jpg`

## Alt Text

Good alt text is descriptive and specific:

- `Luma Energy Blood Orange Mango gummies bottle`
- `Luma Sleep Blueberry Lavender gummies bottle`
- `Luma Daily full ritual bundle with five gummy bottles`

Avoid keyword stuffing, disease claims, or unsupported outcomes.

## Technical Notes

- Use WebP or optimized JPEG for large product images.
- Keep product image dimensions consistent.
- Add width and height attributes where possible to reduce layout shift.
- Prefer Shopify CDN or the production image CDN for final image URLs.
