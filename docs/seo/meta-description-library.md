# Luma Daily — Meta Description Library

Meta descriptions don't directly affect ranking, but they massively affect **CTR from the SERP** — and CTR is a ranking signal. A great meta description can lift CTR by 30%+.

**Rules:**
- 150–160 chars (Google truncates at ~158 on desktop, ~120 on mobile)
- Lead with value, not brand
- Include primary keyword once (natural)
- End with implicit or explicit CTA
- Match the page's actual content (no clickbait — Google rewrites bad metas)

Each major page below has 1 **primary** description (recommended for production) and 2–3 **alternates** for A/B testing or seasonal swaps.

## Universal patterns + reusable phrasing

When writing new descriptions for additional pages, draw from this approved phrase bank to keep voice consistent:

**Premium wellness positioning:**
- "premium wellness gummies"
- "the daily ritual"
- "morning-to-night routine"
- "five clean formulas"
- "real ingredients, honest doses"
- "no fillers, no proprietary blends"

**Compliance-safe benefit phrasing:**
- "supports natural energy and focus"
- "supports calm and stress balance"
- "supports a restful wind-down"
- "supports skin, hair, and nail health"
- "supports daily digestive wellness"

**Conversion language:**
- "build your daily ritual"
- "find the formula that fits"
- "subscribe and save 20%"
- "free shipping on subscriptions"
- "cancel anytime"

**Avoid in metas:**
- "best ever" / "#1" / "guaranteed"
- "cure" / "treat" / "prevent" / disease names
- ALL CAPS, multiple punctuation marks (! !!)
- "click here" / "find out more" / generic CTAs
- Mentions of competitors
